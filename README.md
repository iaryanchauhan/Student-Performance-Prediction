# 🎓 Student Performance Prediction

## 📌 Project Overview

Student Performance Prediction is a Machine Learning project that predicts a student's final mathematics grade based on personal, family, social and academic information.

The project uses a **Random Forest Regressor** to estimate the final grade on a scale of 0–20.

It also includes a user-friendly web application built using Streamlit, where users can enter student information and receive predictions.

## 📊 Dataset

The project uses the Student Performance Dataset from the UCI Machine Learning Repository.

- Dataset file: `student-mat.csv`
- Total records: 395
- Total original features: 33
- Target variable: `G3` (Final Grade)

The previous period grades (`G1` and `G2`) were excluded from model training to avoid using earlier examination results as predictors.

Dataset source: https://archive.ics.uci.edu/dataset/320/student+performance

## 🧠 Machine Learning Model

The project uses a Random Forest Regressor.

### Model Evaluation

| Metric | Result |
|---|---:|
| Mean Absolute Error (MAE) | 3.08 |
| Root Mean Squared Error (RMSE) | 3.87 |
| R² Score | 0.27 |

The model achieved an R² score of approximately 0.27 on the test dataset. This indicates that its predictive performance is limited and can be improved through further experimentation.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd Student_Performance_Prediction
```

### 3. Create a virtual environment

```bash
python3 -m venv venv
```

### 4. Activate the virtual environment

For macOS/Linux:

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Start the Streamlit application using:

```bash
streamlit run app.py
```

The application will open in your browser.
